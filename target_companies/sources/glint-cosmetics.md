# GLINT COSMETICS PVT. LTD. — sources for verification

## Pillar data (from HVT sheet, reviewed) — read this first
`unresolved_pillars: product_improvement` per sheet — but the more
important issue is the **moat** claim ("Manufacturing is certified with
GMP, ISO, FDA, and Halal standards," `needs_verify: no` per HVT). The
HVT sheet's own `gap_source` cites a real FDA warning letter
(fda.gov/inspections-compliance-enforcement-and-criminal-investigations/
warning-letters/glint-cosmetics-pvt-ltd-573468-05312019) documenting
CGMP violations, unapproved new drugs, and a resulting import alert
suspending US exports. **This directly contradicts the moat claim's
"FDA" component, and the HVT tool marking `needs_verify: no` on that
claim looks like a real miss worth flagging back to the pipeline, not
just this one company profile.**

The warning letter itself is dated 2019-05-31 — recommend checking FDA's
current import-alert database directly for up-to-date status before
assuming the situation is unchanged (it may have been resolved, or it
may have worsened; the profile does not assume either).
